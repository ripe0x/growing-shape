# Growing Shape

An onchain drawing game on Ethereum mainnet. Players pay ETH for a verifiably random draw from an
FWA V2 custom pool of ETH-backed Shapes and Draw Packs. One featured Shape grows through gameplay:
surplus funds compositions that add backing to the same token, while its FWA notional decays with
play and partially resets at each composition. Someone eventually wins the accumulated Shape, and a
new cycle begins.

Status: in development, not deployed. See [docs/STATUS.md](docs/STATUS.md).
